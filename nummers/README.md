# Nummers ontleden (werktitel)

Nieuw project naast Voggels: een nummer uit elkaar halen in instrumenten, credits, sporen en samples. Naam en domein volgen nog.

Deze map staat voorlopig in de Voggels-repo, omdat er nog geen eigen repo is. Als de naam vastligt, verhuist hij naar een eigen repo.

- `fase1-datacheck.md`: rapport van fase 1 (wat er aan data is)
- `datacheck/`: scripts en ruwe uitkomsten van die check

Er staat geen audio in deze map, ook geen previews of gescheiden sporen.
